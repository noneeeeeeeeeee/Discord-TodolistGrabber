### Phase 1: Enhanced Context Tracker Logic 🧠 (3 days)

**Temporal Weighting + Safe Anchor + Fast Rollback**

```
Dependencies: Phase 0 complete
Blocks: Phase 3 (scoring needs context updates)
Risk: Medium - changes recommendation behavior
```

#### What's Changing:

- **Temporal Weighting:** Recent feedback gets 1.0x weight, 15-song-old feedback gets 0.3x weight
- **Safe Anchor:** `liked_mood_vector` = weighted average of tracks with `num_likes > 0` (ANY like counts)
- **Fast Rollback:** Disliked genres (dislike_ratio >= 0.4 OR skipped) get stronger penalties if recent
- **Energy Tracking:** Track energy trend (rising/falling) across last 3 songs

#### Algorithm:

```python
# Temporal Weighting Formula
recency_weight = 1.0 - (position_from_recent * 0.05)
# Track 0 (most recent) = 1.0
# Track 14 (oldest in window) = 0.3

# Dislike Penalty (Fast Rollback)
dislike_ratio = num_dislikes / num_active_listeners
if dislike_ratio >= 0.4 or was_skipped:
    penalty = recency_weight * (0.5 if skipped else 0.7)
# Recent skip = 0.7x penalty, old skip = 0.35x penalty

# Safe Anchor Mood (ANY like counts)
liked_tracks = [t for t in history if t.num_likes > 0]
liked_mood_vector = sum(track.mood * recency_weight for track in liked_tracks) / sum(recency_weights)
```

- Test temporal decay (verify track 14 has 30% influence of track 0)
- Test safe anchor (verify ANY like contributes, not just consensus='liked')
- Test fast rollback (verify dislike_ratio >= 0.4 OR skip triggers penalty)
- Test recent dislikes get 3x stronger penalties than old ones

### Phase 3: Enhanced Candidate Scoring 🎯 (3 days)

**Genre Coherence + Energy Flow + Updated Mood Alignment**

```
Dependencies: Phase 1 (needs liked_mood_vector), Phase 2 (needs pool sources)
Blocks: Phase 4 (selection needs scores)
Risk: High - core recommendation quality
```

#### What's Changing:

- **Genre Coherence Scoring:** Reward tracks matching session's genre profile
  - Formula: `overlap_ratio = len(candidate_genres ∩ session_genres) / min(len_cand, len_session)`
  - Weight: 25% of base score
- **Energy Flow Scoring:** Penalize jarring energy jumps, reward smooth transitions
  - Penalty: -0.5 for sharp jump (delta > 0.4)
  - Bonus: +0.3 for continuing trend (ramping up/down with session)
  - Weight: 10% of base score
- **Updated Mood Alignment:** Prioritize safe anchor over average mood
  - Formula: `0.4 × (1 - dist_to_avg) + 0.6 × (1 - dist_to_liked)`
  - Safe anchor gets 60% weight (tracks users explicitly liked)
  - Weight: 35% of base score

#### New Score Composition:

```python
base_score = (
    0.35 * mood_alignment +         # Mood (with safe anchor)
    0.25 * genre_coherence +        # NEW: Genre consistency
    0.10 * energy_flow +            # NEW: Energy pacing
    0.30 * collaborative_score      # Existing: user-user similarity
)

# Then apply temporal-weighted dislike penalties
for genre in candidate.genres:
    if genre in context.disliked_tags:
        base_score *= (1.0 - context.disliked_tags[genre])
```

### Phase 4: Selection Logic & Diversity Injection 🎰 (2 days)

**Stochastic Selection + Echo Chamber Prevention + Safe Gate**

```
Dependencies: Phase 3 (needs scores)
Blocks: Phase 5 (telemetry needs selection outcomes)
Risk: Medium - changes playback behavior
```

#### What's Changing:

- **Diversity Injection:** After 5 consecutive "safe" picks (score ≥ 8.0), force a discovery track
  - Filter to `pool_d_discovery` candidates with score ≥ 7.0
  - Prevents echo chamber effect
  - Resets counter after injection
- **Stochastic Selection:** Top 5 candidates → weighted random choice
  - Weights: `score^2` (quadratic amplifies quality differences)
  - Non-deterministic but quality-biased
  - More "magical" than always picking #1
- **Safe Gate Loop:** Retry up to 3 times if resolution fails quality check
  - Criteria: `heuristic_score ≥ 8.0` AND `len(spam_flags) == 0`
  - If all retries fail: fallback to score ≥ 7.0 threshold

#### Files Modified:

- `__init__.py` (get_recommendations_for_track, new instance variable)

#### Testing:

- Test diversity injection: 5 safe picks → verify 6th is from pool_d
- Test stochastic selection: run 100 times → verify distribution favors top scores
- Test safe gate: mock low-quality tracks → verify 3 retries + fallback

### Phase 7: Performance Optimization ⚡ (2 days)

**Async Batching + Caching + Profiling**

```
Dependencies: Phase 6 (need baseline performance metrics)
Blocks: None (final phase)
Risk: Low - optimizations only
```

#### Optimizations:

1. **Last.fm Request Batching:**

   - Current: 4 sequential requests (~4s total)
   - Target: 1 parallel batch (~1.5s total)
   - Use `asyncio.gather(pool_a, pool_b, pool_c, pool_d)`

2. **Warm Start Pool Caching:**

   - Cache Pool B/C for 5 minutes (key = artist_list + tag_list)
   - Reduces API calls by 60% in long sessions
   - Invalidate on focus_genres change

3. **Genre Coherence Optimization:**

   - Pre-convert `session_focus_genres` to set
   - Use set intersection (O(n) vs O(n\*m))
   - Target: <5ms for 100 candidates

4. **Scoring Loop Profiling:**
   - Add timing decorators
   - Target: score 100 candidates in <50ms
   - Vectorize mood_distance if needed (numpy)
