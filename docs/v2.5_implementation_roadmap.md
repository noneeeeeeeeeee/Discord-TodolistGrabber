## 📊 Implementation Phases

### Phase 0.5: Resilient Parsing Engine with Multi-Stage Self-Healing 🎭 (3-4 days)

**CRITICAL PRE-FOUNDATION - Must Complete BEFORE Phase 0**

```
Dependencies: None
Blocks: Phase 0 (data model needs track_type field), Phase 2 (pool branching)
Risk: CRITICAL - Without this, OST/anime/musical/game soundtrack content causes autoplay failure
Impact: Eliminates ~150 LOC of complex Branch A entity-based pool logic, replaces with canonical data
```

#### The Problem:

**Franchise music breaks artist-centric systems.** When a user plays "Sera's Confession Sing-Along - Hazbin Hotel", Gemini correctly identifies "Hazbin Hotel" as the primary entity, but Last.fm's `artist.getTopTracks("Hazbin Hotel")` returns **show episodes** (e.g., "Season 1, Ep 2"), not music. These get filtered as spam → empty candidate pool → autoplay fails.

**Root Cause:** OST content has **ambiguous artist attribution**. YouTube titles like "Poison - Hazbin Hotel Official Music Video" could be artist="Hazbin Hotel" (franchise umbrella) OR artist="Blake Roman" (actual singer). Gemini guesses inconsistently, Last.fm rejects guesses.

**The Solution: Resilient Parsing Engine (Multi-Stage Waterfall with Self-Healing)**

Replace simple 2-pass waterfall with **intelligent multi-stage escalation** that adapts to parsing difficulty and self-heals over time:

```
Parse Flow (3-Stage Escalation):
┌─────────────────────────────────────────────────────────────────┐
│ Stage 0: Cache Check                                            │
│ ├─ Hit (is_canonical=True) → Return canonical (indefinite TTL) │
│ ├─ Hit (is_best_guess=True) → Check 7-day TTL, retry if stale │
│ └─ Hit (both False) → Check adaptive TTL (1-30 days), retry    │
└─────────────────────────────────────────────────────────────────┘
                           ↓ Cache miss or stale
┌─────────────────────────────────────────────────────────────────┐
│ Stage 1: Gemini 2.5 Flash-Lite (Fast & Cheap)                  │
│ ├─ Generate 9 Deezer queries (3 sets × 3 variations)          │
│ │  Set A: Artist-focused ("Blake Roman Poison")               │
│ │  Set B: Entity-focused ("Hazbin Hotel Poison soundtrack")   │
│ │  Set C: Title-focused ("Poison from Hazbin Hotel")          │
│ ├─ Deezer search with 9 queries (85% confidence threshold)    │
│ └─ Success → is_canonical=True, cache indefinitely ✅          │
└─────────────────────────────────────────────────────────────────┘
                           ↓ All 9 queries failed
┌─────────────────────────────────────────────────────────────────┐
│ Stage 2: Gemini 2.5 Flash + Grounding + Thinking (Smart)       │
│ ├─ Check grounding quota: 500/day free tier × 3 keys = 1,500  │
│ ├─ Pass failed queries from Stage 1 for context awareness     │
│ ├─ ENABLE thinking (budget=-1) for intelligent query gen      │
│ ├─ Generate 3 refined queries with Google Search grounding    │
│ │  (Grounding provides web-sourced canonical names)           │
│ │  (Thinking enables multi-step reasoning about artist)       │
│ ├─ Deezer search with 3 refined queries (75% threshold)       │
│ └─ Success → is_canonical=True, cache indefinitely ✅          │
└─────────────────────────────────────────────────────────────────┘
                           ↓ Deezer still failed (obscure/unofficial)
┌─────────────────────────────────────────────────────────────────┐
│ Stage 3: Best Guess Extraction (Grounded Fallback)             │
│ ├─ Use same Flash + Grounding + Thinking (already quota'd)    │
│ ├─ Extract artist/title directly from grounding metadata      │
│ │  Prompt: "Based on web search, provide most likely artist"  │
│ ├─ Set is_best_guess=True (MEDIUM confidence, 7-day TTL)      │
│ └─ OR if no grounding: Use Flash-Lite parse, both flags=False │
│    Cache with adaptive TTL (1-30 days based on failure type)  │
└─────────────────────────────────────────────────────────────────┘
```

**Why This 3-Stage Approach?**

- ✅ **Stage 1 (Flash-Lite)**: Fastest/cheapest, handles 90% of normal music with 9 query variations
- ✅ **Stage 2 (Flash + Grounding + Thinking)**: FREE web search (500/day/key × 3 = 1,500/day), COMBINED with thinking for intelligent OST parsing
  - **Grounding** provides canonical web-sourced names ("Blake Roman" not "Hazbin Hotel")
  - **Thinking** enables multi-step reasoning about artist attribution
  - **Both work together**: Grounding gives facts, thinking analyzes them
- ✅ **Stage 3 (Best Guess Extraction)**: Reuse same Flash+Grounding from Stage 2 to extract artist/title directly when Deezer fails
- ✅ **No Pro Model Needed**: Flash can think + ground simultaneously, Pro is overkill for parsing
- ✅ **Multi-Key Rotation**: 3 API keys = 3× quota (1,500 grounding/day supports ~15,000 tracks/day)
- ✅ **Self-Healing Cache**: Stale non-canonical entries auto-retry after TTL, coverage improves over time
- ✅ **Cost**: FREE on free tier (generous limits), paid tier ~$0.0015/track average
- ✅ **Deezer**: No API key, canonical metadata for 95%+ of commercial music, rate limit friendly (3600/hour)

**Google Grounding Quota Management (Free Tier):**

```python
# Per API key (free tier):
# - 500 grounding requests per day (resets midnight Pacific)
# - Shared limit between Flash and Flash-Lite
# - With 3 keys: 500 × 3 = 1,500 grounding requests/day

# Supports ~15,000 tracks/day:
# - Stage 1 (Flash-Lite): 90% success (13,500 tracks) → 0 grounding used
# - Stage 2 (Flash + Grounding): 10% escalation (1,500 tracks) → 1,500 grounding used ✅
# - Stage 3 (Pro): <1% escalation (<150 tracks) → minimal additional grounding

class GroundingQuotaManager:
    def __init__(self, api_keys: List[str]):
        self.api_keys = api_keys  # 3 keys for rotation
        self.daily_quota = 500 * len(api_keys)  # 1,500 total
        self.used_today = 0
        self.current_key_index = 0
        self.reset_time = self._get_next_midnight_pacific()

    def can_use_grounding(self) -> bool:
        """Check if grounding quota available."""
        if datetime.now() >= self.reset_time:
            self._reset_quota()
        return self.used_today < self.daily_quota

    def get_next_api_key(self) -> str:
        """Rotate through API keys for load balancing."""
        key = self.api_keys[self.current_key_index]
        self.current_key_index = (self.current_key_index + 1) % len(self.api_keys)
        return key

    def increment_usage(self):
        """Track grounding usage."""
        self.used_today += 1
        logger.info(f"Grounding quota: {self.used_today}/{self.daily_quota}")
```

#### Architecture Changes:

**1. New GeminiService Methods (gemini_service.py)**

```python
class GeminiService:
    def __init__(self, api_keys: List[str]):
        self.quota_manager = GroundingQuotaManager(api_keys)

    async def generate_deezer_queries_lite(
        self,
        title: str,
        failed_queries: List[str] = None
    ) -> List[str]:
        """
        Stage 1: Use Flash-Lite (no thinking) to generate 9 Deezer queries.

        Returns 3 sets of 3 variations:
        - Set A (Artist-focused): Focus on canonical artist name
        - Set B (Entity-focused): Focus on franchise/anime/game name
        - Set C (Title-focused): Focus on clean title without suffixes
        """
        model = "gemini-2.5-flash-lite"  # 15 RPM, fastest, no thinking capability
        prompt = f"""
        Generate 9 Deezer search queries for: "{title}"

        Return 3 sets of 3 variations each:

        Set A - Artist-focused (assume artist is PERSON, not franchise):
        1. [canonical_artist] [clean_title]
        2. [canonical_artist] [clean_title] [album_hint]
        3. [main_artist_if_collab] [clean_title]

        Set B - Entity-focused (assume artist is FRANCHISE):
        1. [franchise] [clean_title] soundtrack
        2. [franchise] OST [clean_title]
        3. [franchise] [clean_title] original

        Set C - Title-focused (clean title variations):
        1. [clean_title] [year_if_known]
        2. [clean_title] [language] version
        3. [clean_title] official

        Rules:
        - Remove YouTube suffixes (Official Audio, Lyric Video, Nightcore, etc.)
        - Expand acronyms (JJK → Jujutsu Kaisen)
        - For covers, use original artist
        - Remove pipes, season markers, "ft.", "sing-along"

        Return JSON: {{"queries": ["query1", "query2", ...], "track_type": "music|ost|anime_opening|game_soundtrack"}}
        """
        # No thinking budget needed - Flash-Lite doesn't support thinking
        response = await self.client.models.generate_content(
            model=model,
            contents=prompt,
            config=types.GenerateContentConfig(
                response_mime_type="application/json"
            )
        )
        return json.loads(response.text)

    async def generate_deezer_queries_grounded(
        self,
        title: str,
        failed_queries: List[str]
    ) -> List[str]:
        """
        Stage 2: Use Flash + Google Grounding + Thinking to generate 3 refined queries.

        - Grounding provides web-sourced canonical names for OST/anime content
        - Thinking enables multi-step reasoning about artist attribution
        - Flash supports BOTH tools simultaneously (thinking_budget=-1)
        """
        if not self.quota_manager.can_use_grounding():
            logger.warning("Grounding quota exhausted, skipping Stage 2")
            return []

        api_key = self.quota_manager.get_next_api_key()
        model = "gemini-2.5-flash"  # 10 RPM, supports grounding + thinking

        grounding_tool = types.Tool(
            google_search=types.GoogleSearch()
        )

        prompt = f"""
        Previous Deezer queries failed: {failed_queries}

        Use Google Search to find the CANONICAL artist/album for: "{title}"

        Think through:
        1. Is this OST (game/anime soundtrack)?
        2. Is this a cover/remix (use original artist)?
        3. Is this a collaboration (who's the primary artist)?
        4. Are there multiple artists with this name?

        Then generate 3 refined Deezer queries:
        1. [canonical_artist_from_web] [canonical_title_from_web]
        2. [canonical_artist] [canonical_title] [album_from_web]
        3. [canonical_artist] album:[album_name_from_web]

        Return JSON: {{"queries": ["query1", "query2", "query3"], "confidence": "high|medium|low", "reasoning": "brief explanation"}}
        """

        response = await self.client.models.generate_content(
            model=model,
            contents=prompt,
            config=types.GenerateContentConfig(
                tools=[grounding_tool],
                response_mime_type="application/json",
                thinking_config=types.ThinkingConfig(thinking_budget=-1)  # Enable dynamic thinking
            ),
            api_key=api_key
        )

        self.quota_manager.increment_usage()
        return json.loads(response.text)

    async def generate_fallback_metadata(
        self,
        title: str,
        failed_queries: List[str]
    ) -> dict:
        """
        Stage 3 Fallback: Use Flash + Grounding + Thinking to extract best guess metadata.

        Reuses the same Flash+Grounding+Thinking connection from Stage 2, but instead of
        generating Deezer queries, directly extracts artist/title from web sources.

        Sets is_best_guess=True (7-day TTL) for adaptive expiration.
        """
        if not self.quota_manager.can_use_grounding():
            logger.warning("Grounding quota exhausted, falling back to regex extraction")
            return self._regex_fallback(title)

        api_key = self.quota_manager.get_next_api_key()
        model = "gemini-2.5-flash"

        grounding_tool = types.Tool(
            google_search=types.GoogleSearch()
        )

        prompt = f"""
        All Deezer searches failed for: "{title}"
        Failed queries: {failed_queries}

        Use Google Search to find the MOST LIKELY canonical metadata.

        Think through:
        1. What type of content is this (music/OST/anime/game)?
        2. Who is the ACTUAL artist (person vs franchise)?
        3. What is the CLEAN title (remove YouTube suffixes)?
        4. Is this official or fan-made?

        Return the BEST GUESS metadata for Last.fm scrobbling:
        {{
            "artist": "canonical artist name",
            "title": "clean track title",
            "album": "album name if known, else empty string",
            "confidence": "high|medium|low",
            "reasoning": "why this is the best guess",
            "track_type": "music|ost|anime_opening|game_soundtrack|cover|fan_made"
        }}
        """

        response = await self.client.models.generate_content(
            model=model,
            contents=prompt,
            config=types.GenerateContentConfig(
                tools=[grounding_tool],
                response_mime_type="application/json",
                thinking_config=types.ThinkingConfig(thinking_budget=-1)  # Enable thinking
            ),
            api_key=api_key
        )

        self.quota_manager.increment_usage()
        result = json.loads(response.text)
        result["is_best_guess"] = True  # Mark for 7-day TTL
        return result

    def _regex_fallback(self, title: str) -> dict:
        """
        Emergency fallback: Regex-based parsing (no Gemini quota left).
        """
        # Regex extraction logic (existing v1 implementation)
        chunks = grounding_metadata.get("groundingChunks", [])
        web_results = [chunk["web"]["title"] for chunk in chunks]

        prompt = f"""
        Deezer search failed, but Google found these results: {web_results}

        Extract the most likely artist and title for music playback.

        Return JSON: {{
            "artist": "best guess artist",
            "title": "best guess title",
            "confidence": "medium|low"
```

**Self-Healing Cache Strategy:**

```python
class CacheManager:
    def get_parsing(self, youtube_id: str) -> Optional[ParsingEntry]:
        """
        Smart cache retrieval with self-healing retry logic.
        """
        entry = self._load_from_disk(youtube_id)
        if not entry:
            return None

        # Canonical entries never expire (indefinite TTL)
        if entry.is_canonical:
            return entry

        # Best guess entries expire after 7 days
        if entry.is_best_guess:
            age_days = (time.time() - entry.parsed_at) / 86400
            if age_days > 7:
                logger.info(f"Best guess entry stale ({age_days:.1f} days), re-parsing")
                return None  # Trigger re-parse
            return entry

        # Fallback entries use adaptive TTL based on failure reason
        if entry.retry_after_days is not None:
            age_days = (time.time() - entry.parsed_at) / 86400
            if age_days > entry.retry_after_days:
                logger.info(f"Fallback entry stale (TTL {entry.retry_after_days} days), re-parsing")
                entry.last_retry_attempt = time.time()
                return None  # Trigger self-healing retry
            return entry

        # Legacy entries (no retry_after_days) default to 120 days
        age_days = (time.time() - entry.parsed_at) / 86400
        if age_days > 120:
            return None
        return entry

    def calculate_adaptive_ttl(self, failure_reason: str) -> int:
        """
        Calculate TTL based on failure type for self-healing.
        """
        ttl_map = {
            "deezer_timeout": 1,        # Retry soon (network issue)
            "no_match": 7,              # Retry weekly (might get indexed)
            "quota_exhausted": 1,       # Retry tomorrow (quota resets)
            "grounding_failed": 3,      # Retry in 3 days
            "unofficial_content": 30,   # Retry monthly (unlikely to change)
            "nightcore": 30,            # Remixes don't get canonical metadata
            "mashup": 30,               # Fan-made content
            "cover": 14,                # Covers might get official releases
        }
        return ttl_map.get(failure_reason, 7)  # Default 7 days
```

  - Filter to `pool_d_discovery` candidates with score ≥ 7.0

  - Prevents low-quality tracks from being selected
